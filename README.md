# محاسبه

ابزار محاسبهٔ تبدیل رهن به اجاره با قابلیت افزایش سالانه.

## امکانات

- محاسبهٔ مبلغ کامل رهن یا کامل اجاره از روی ترکیب رهن + اجارهٔ ماهانه
- نرخ تبدیل ماهانه قابل تنظیم (پیش‌فرض ۳٪)
- اعمال درصد افزایش سالانه (مثلاً ۳۰٪) روی کل مبلغ
- تعیین دوبارهٔ رهن و اجارهٔ جدید بعد از افزایش، به‌صورت زنده و دوطرفه (تغییر هرکدام، دیگری را خودکار حساب می‌کند)

## نحوهٔ استفاده

1. رهن و اجارهٔ فعلی را وارد کنید.
2. نتیجهٔ «کامل رهن» و «کامل اجاره» را ببینید.
3. درصد افزایش سالانه را وارد کنید تا مبالغ جدید محاسبه شود.
4. رهن یا اجارهٔ جدید دلخواه‌تان را وارد کنید تا طرف مقابل به‌صورت خودکار و هم‌ارزش محاسبه شود.

## فرمول محاسبه

با نرخ تبدیل ماهانهٔ `r` (به‌صورت اعشاری، مثلاً ۳٪ = 0.03):

```
اگر کامل رهن باشد = رهن + (اجاره ÷ r)
اگر کامل اجاره باشد = (رهن × r) + اجاره
```

پس از اعمال درصد افزایش سالانه `i` (مثلاً ۳۰٪ = 0.30)، هر دو مقدار بالا در `(1 + i)` ضرب می‌شوند و مبنای محاسبهٔ رهن/اجارهٔ جدید قرار می‌گیرند.
